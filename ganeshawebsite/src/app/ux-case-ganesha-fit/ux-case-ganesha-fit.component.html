Scenario

1️⃣ User / Scenario

Who / User: Gym member / fitness enthusiast. Someone who wants to explore gym facilities, join classes, manage subscription, and contact a coach.

Wants / Needs:

  • See the different machines available at the gym
  • Browse group classes
  • Manage their subscription
  • Book a personal coach
  • Find a club nearby
  • Contact the gym or staff
2️⃣ Tasks / Features (SCRUM style)
User Story Task / Feature
Explore machines List of machines, descriptions, usage tips
Browse classes Schedule, class info, sign up / cancel
Manage subscription View plan, upgrade/downgrade, payment info
Book a coach List available coaches, book session, calendar integration
Find a club Search clubs by location, map, details
Contact Contact form, email, phone, chat option
3️⃣ Optional: Acceptance Criteria / UX Notes
  • Machines → Filter by type, highlight availability
  • Classes → Responsive schedule, clear signup process
  • Subscription → Update plan easily, confirmation of changes
  • Coach → Book sessions with confirmation and calendar integration
  • Find a club → Search bar + map view, responsive
  • Contact → Form or direct email/phone link, easy to access
